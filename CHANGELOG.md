# Changelog

## 0.1.0-beta.1

The first release: a pixel-art sprite editor and an animator graph editor for `just_game_engine_editor`, and the document core under them.

- **Document core** (`package:just_sprite_editor/document.dart`, pure Dart, no widgets and no `dart:io`): `SpriteDocument` (layers, frames, canvas-sized cels, tags with direction, loop and events, palette, export options), `DocumentEditor` (undo as dirty-rectangle cel patches and structure snapshots, one stroke one step, saved-point tracking, a memory budget that counts what each step keeps alive), `Raster` (line, pixel-perfect paths, brushes, rectangle, ellipse, scanline fill, symmetry, replace colour) and `SelectionMask`.
- **Files**: `JspriteCodec` (the `.jsprite` project; cels deflated with `just_deflate`), `SheetExporter` (PNG + Aseprite-format JSON, with `meta.just` for clip loop flags and frame events — what `just_game_engine`'s atlas loader reads), `SheetImporter` (an image, or a sheet cut by grid), `AsepriteImporter` (`.ase` / `.aseprite`: layers, raw, compressed and linked cels, durations, tags, palette; RGBA, greyscale and indexed), `GifEncoder`, `PngEncoder`, and `Palettes` (presets; `.gpl`, JASC `.pal` and `.hex`).
- **Damaged files say so**: a `.jsprite`, `.aseprite` or image that is cut short, has a value of the wrong type, an id used twice, a cel outside the canvas or a size that is a lie is refused with a `FormatException` and a message, before anything big is made from it. The studio shows the message.
- **Sizes**: a sprite is at most 2048 × 2048, and the codec never writes one bigger. An image up to 8192 opens to be cut into frames, and is saved once it fits. A sheet larger than 16384 either way is not exported (the project still saves, and says why). The canvas keeps up with the pen up to about 512 × 512.
- **The studio** (`SpriteStudio`): a zoomable canvas with checkerboard, pixel grid, onion skins, selection outline, symmetry axes and brush preview; pencil, eraser, fill, colour picker, line, rectangle, ellipse, rectangular select and move, with brush size, pixel-perfect strokes, mirror drawing, filled shapes and contiguous fill; flip, rotate, delete, replace colour, crop, canvas size, and slice into frames (one undo step); an HSV + hex colour panel with the sprite's palette and presets; layers (visibility, lock, opacity, order, duplicate, merge down); a layers × frames timeline with per-frame duration, tags (direction, loop, events), playback per tag and onion skin; a list of the project's sprites and an Import… button; Aseprite-style shortcuts, with Cmd on macOS; undo and redo; trackpad pan and pinch.
- **Saving** writes the project and re-exports the sheet and atlas beside it, each file whole or not at all. The first save keeps what was there before as `name.original.png` and `name.original.json`. A new sprite is offered a name nothing has yet, and the studio asks before it writes over another sprite or an atlas it did not write.
- **The animator graph editor** (`AnimatorGraphEditor`): states as draggable nodes, transitions as arrows, Entry and Any State; an inspector for states (clip, speed, loop, a Timeline Player's `.timeline.json`, a blend tree over one or two number parameters) and transitions (conditions, exit time, blend time, priority); parameters with a binding dropdown; one state per clip of an atlas or a 3-D model (`.glb`, `.gltf`) in a click; validation warnings; undo; the live state of a running game lit on the graph. It edits animator graph format 2.
- **`SpriteStudioModule`** (`package:just_sprite_editor/editor.dart`): both editors as workspaces of `just_game_engine_editor` (through `just_editor_core`'s module contract), asset actions, a toolbar button and two prefabs, *Animated sprite* and *Animated character*. Installed from the Asset Store, it registers itself.
- Every library of the package is design-time only; a game needs none of it, since the engine plays what the studio saves.
